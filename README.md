# Тьюринг-арена — локальный алгоритмический бот

Python 3.11, SQLite, только стандартная библиотека. Во время обработки нет интернета, LLM API, готовых языковых моделей и скачиваний. Текущая версия `arena v1` отделена от исторического spike.

## Запуск на Windows

Из корня репозитория:

```powershell
python -X utf8 main.py --chat
python -X utf8 main.py --ask "Почему после дождя иногда появляется радуга? Объясни простыми словами."
```

По умолчанию выдача планируется через 3–40 секунд от начала обработки: `clamp(3 + 0.12 * длина + случайное(-1,1),3,40)`. Вычисление входит в общий интервал. Внешний дедлайн сильнее ожидания. Ответ идёт в stdout; время и диагностика — в stderr.

Для разработки, без искусственной задержки и с объяснением выбора:

```powershell
python -X utf8 main.py --ask "Еду в Астану не зимой, а летом. Что взять?" --fast --json
```

`--fast` и `--json` не применяются к сценическому текстовому выводу. `--seed 42` воспроизводит вариативность; `--db путь` подключает совместимую локальную БД, не пересоздавая её. Новая сессия начинается без памяти прошлого процесса.

## Алгоритм

Лексический слой находит понятия и известные формы, включая короткие фразы. Ограниченное сопоставление основ помогает с некоторыми падежными окончаниями. Правила учитывают тип вопроса, событие, участника, отрицание, сезон и предыдущую реплику. Полные строки контрольных вопросов не являются ключами маршрутизации.

Содержание берётся из фактов и коротких смысловых частей в SQLite. Объяснение явления, практический совет и социальная реакция имеют разные планы. Сборка использует доступные формы слов, сохраняет предпочтения персонажа, проверяет окончательный текст. В --json видны понятия, использованные факты и условия выбора.

Обработка выполняется в отдельном Windows-compatible spawn процессе с лимитом 2 секунды. Ошибка или зависание дают русский резерв. Родитель управляет задержкой и выдачей. Память применяется после успешной передачи; тот же request_id не генерирует новый вариант. Для внешнего sink при частичном побочном эффекте с ошибкой требуется идемпотентность/подтверждение получателя.

## Локальные данные

`data/demo.sqlite3` подготовлена заранее; воспроизводимый источник — `data/demo.json`. `arena/data.py` создаёт стандартную БД при её отсутствии и не перезаписывает существующую. GPU, API-ключи и дополнительные pip-пакеты не нужны. Источники фактов записаны в данных: NOAA и официальный Visit Astana; URL во время исполнения не открываются.

Таблицы: concepts, forms, facts, groups, knowledge, metadata. Схема и интерфейсы — в `docs/pipeline/contracts.md`. Адаптер читает прежний формат v0 в пределах имеющихся в нём знаний. Произвольная иная схема требует адаптера. Словарь даёт формы/понятия; новые причинные связи и ситуации требуют соответствующих данных и операций.

Демонстрационные социальные части и персонаж подготовлены с помощью ИИ и требуют проверки/настройки участниками. Они не выдаются за написанный участниками корпус. Готовые LLM в исполняемом решении не используются.

## Проверки

```powershell
python -X utf8 -m unittest discover -s tests -v
python -X utf8 scripts/benchmark.py --count 1000
```

Проверяются контрольная тройка, перефразировки и отрицательные контрпримеры, атрибуция памяти, замена БД, безопасные вычисления, длина, реальное зависание процесса, ошибка доставки и дедлайн. `docs/pipeline/audit.md` хранит первоначальный независимый аудит с найденными проблемами; последующий отчёт о фиксе не заменяет его и не выдаётся за свежий holdout.

Исторический spike лежит в `docs/pipeline/spikes/`, production его не импортирует. Его показатели 16/25 и 0/3 не описывают новую версию. Текущая контрольная тройка проходит 3/3; это ещё не доказательство универсальности или человечности.

## Границы и команда

Покрытие ограничено подготовленными понятиями, отношениями и правилами. Текущая погода, курс валют, чужие личные сведения и расположение ширм неизвестны. Для неизвестного отношения допустимо уточнение/признание незнания. Гарантий победы нет.
