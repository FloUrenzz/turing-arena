# Тьюринг-арена — алгоритмический прототип

Локальный русскоязычный бот на Python 3.11 и SQLite. Только стандартная библиотека: нет готовых моделей, весов, LLM API и сетевых запросов во время обработки вопросов.

Текущий код — исследовательский прототип стадии 3, а не готовая конкурсная версия. Универсальность и человечность не подтверждены: новый отложенный набор показал 16/25 поддержанных формулировок и 9/10 корректных признаний незнания. На первом наборе после правок: 20/25, но это регрессия, а не новая независимая оценка. Подробные исходные результаты сохранены рядом с кодом.

## Запуск на Windows

Из корня репозитория:

```powershell
cd docs/pipeline/spikes/s01_symbolic
python -X utf8 main.py --chat
```

Одиночный вопрос и диагностическая информация:

```powershell
python -X utf8 main.py --ask "Что выберешь: чай или кофе?" --json
```

Диалог с зависимой от длины задержкой:

```powershell
python -X utf8 main.py --chat --timed
```

Существующая `data/demo.sqlite3` содержит тестовые локальные данные. При необходимости `python seed.py` создаёт/обновляет демонстрационную БД. Не запускайте seed против базы сокомандника: `--db` принимает отдельный путь к совместимой БД. Произвольная другая схема требует адаптера.

Режим `--timed` планирует выдачу через 3–40 секунд от начала обработки с учётом длины и небольшой случайности. Проверено реальными запусками: короткий арифметический ответ около 3.6 с, объяснение около 6.7 с. Это не защита от зависания движка; отдельный процесс, watchdog и конкурсный протокол передачи ещё предстоит реализовать.

## Проверки

Из корня репозитория:

```powershell
python -X utf8 -m unittest discover -s docs/pipeline/spikes/s01_symbolic -p "test_*.py" -v
python -X utf8 docs/pipeline/spikes/evaluation/evaluate.py --project docs/pipeline/spikes/s01_symbolic --cases docs/pipeline/spikes/evaluation/cases_v2.json --output local/evaluation.json
```

12 unit-проверок проходят. Независимые вопросы зафиксированы до реализации соответствующей попытки; отчёты разделяют первичную оценку, новую проверку и регрессию. 1 000 последовательных вызовов обработаны без пустых/слишком длинных ответов. Запрет socket-вызовов в проверке не заменяет видеодемонстрацию на физически отключённом от сети ноутбуке.

## Структура и ресурсы

- `docs/pipeline/plan.md` — текущий план и критерии.
- `docs/requirements/technical-check-2026-11-23.md` — требования письма и DOCX-формы организаторов.
- `docs/pipeline/spikes/s01_symbolic/` — экспериментальный движок, seed, тестовая БД, CLI и тесты.
- `docs/pipeline/spikes/evaluation/` — отложенные вопросы, независимый harness, исходные отчёты.

Для запуска не нужны GPU, API-ключи или скачивания моделей. Python и SQLite-файлы должны быть подготовлены на компьютере заранее. Проверенная среда: Windows, Python 3.11.6; версия SQLite фиксируется установленным Python. Список дополнительных pip-зависимостей пуст.

Словарь хранит формы и понятия; отдельные факты и причины дают содержание; память различает собеседника и персонажа; правила разбирают вопрос и собирают фразу. Простое увеличение числа слов не добавляет понимания новых отношений. Научное объяснение, практический совет и социальная реакция из обязательной контрольной тройки пока требуют расширения движка и знаний.
