## S-01 — Можно ли получить короткие осмысленные реплики на маленькой SQLite-БД и правилах?

**Скрипты:** `spikes/s01_symbolic/seed.py`, `engine.py`, `main.py`, `test_spike.py`.

**Ответ:** частично. Известные понятия и поддержанные операции обобщаются на разные формулировки; универсальная беседа не достигнута. Независимую отложенную оценку проводит родительский агент отдельно.

**Факты:** Python 3.11.6; SQLite 3.42.0; 20 понятий, 9 фактов персонажа; БД 28 672 байта. Семь unittest прошли, первый запуск: `Ran 7 tests in 0.106s / OK`. Семь последовательных запросов через Bot.answer обработаны суммарно за 5.587 мс в одном фактическом прогоне. Это локальный замер, не гарантия задержки на всех устройствах. Реальные ответы: «Почему ты не любишь чай?» → «Вообще-то я люблю чай. С ним уютнее сидеть вечером.»; «Сколько будет 17 плюс 26?» → «43.»; «Переверни слово „мир“» с угловыми кавычками → «рим.»; неизвестная погода на Марсе → уточнение с fallback=true. Никаких сетевых зависимостей и сторонних пакетов в реализации нет. Отдельный сетевой блок на уровне ОС этим прогоном не устанавливался. Режим --timed реализован; фактическая многосекундная выдача здесь ещё не измерялась.

**Следствие для плана:** словарь обеспечивает распознавание и известные формы, факты дают содержание, правила связывают их. Пополнение словаря само по себе не обеспечивает универсальность; сложные субъекты, отрицания, неизвестные варианты и составные вопросы должны проверяться отдельно. Нужен следующий контракт лексики и отдельная конкурсная оболочка с процессным тайм-аутом; текущий CLI не даёт гарантии выдать резерв при зависании.
