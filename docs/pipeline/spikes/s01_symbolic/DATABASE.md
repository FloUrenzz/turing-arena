# Подключение другой БД к исследовательскому прототипу

Это описание текущего эксперимента, не окончательный контракт конкурсной системы. До массового наполнения согласуем расширения для причинных объяснений, советов и социальных ситуаций из технической формы.

`python main.py --db путь/к/lexicon.sqlite3 --chat` использует указанный локальный SQLite-файл. Форма CLI не определяет его произвольную схему: таблицы должны соответствовать `schema.sql`, извлечённой из работающей демонстрационной БД. Для другой схемы нужен адаптер; структура не угадывается автоматически.

- `concepts`: идентификатор понятия, лемма, готовая форма винительного падежа, род, определение.
- `forms`: нормализованная словоформа, идентификатор понятия, часть речи и признаки. Поиск приводит к нижнему регистру и заменяет `ё` на `е`; исходный текст вопроса сохраняется отдельно. Демо-разметка неполна: unknown/unannotated не считать полноценной морфологией.
- `facts`: идентификатор факта, субъект, отношение, объект, числовое предпочтение, причина. Предпочтения персонажа используют `subject=self`, `predicate=likes`; положительное значение означает предпочтение, отрицательное — неприязнь. Факты имени/роли также читаются из БД.
- `groups`: связь категории и понятия. Точные столбцы/ключи — в извлечённом SQL.

Движок не выводит личное предпочтение или причину из одного названия слова. Добавление словоформ расширяет распознавание; новые знания требуют фактов/отношений и поддерживаемых алгоритмом операций. Не подставляйте местоимение персонажа вместо неизвестного человека из вопроса.

Для первого подключения сокоманднику достаточно скопировать демонстрационную БД, изменить несколько словоформ/фактов и проверить, что ответы изменились без правок Python. Такой эксперимент выполнен: имя стало «Лера», выбор сменился с чая на кофе. Потом согласуем полноценный формат и переносим данные через проверяемый адаптер.

`seed.py` предназначен для демонстрационных данных. Не запускайте его против чужой наполненной БД. Происхождение данных, права и способ подготовки нужно фиксировать; текущие демо-примеры подготовлены с помощью ИИ.
