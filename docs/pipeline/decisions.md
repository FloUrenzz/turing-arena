# Решения

## 2026-11-23 — Новый движок отделён от spike

Старый эксперимент подтвердил локальную работоспособность, но давал 0/3 контрольных ответов. Production `arena/` написан отдельно и не импортирует `spikes`. Лексика, факты, смысловые части, правила и runtime разделены; свободная генерация нейросетью не используется.

## 2026-11-23 — Проверяем отношение и область применения, а не одно знакомое слово

Независимый аудит выявил подмену причины исчезновения интернета личным отношением к дождю и оптику для изображения радуги на логотипе. Личная причина теперь требует личного предиката или настоящего короткого продолжения; научное объяснение ограничено физическим контекстом. Для неизвестного отношения предпочтителен честный отказ. Ограничение покрытия сохраняется и записывается в результатах.

## 2026-11-23 — Валидация и расчёт состояния до доставки

Аудитор воспроизвёл двойной sink после неправильного updates. Payload валидируется полностью, новое состояние рассчитывается до публикации, после успешного sink выполняются только присваивания. Внешний частично успешный sink по-прежнему требует собственной идемпотентности.

## 2026-11-23 — Локальная SQLite без привилегий hard link

Hard link работал в системном temp, но не в рабочей папке Windows. Создание БД теперь публикует файл атомарным Windows rename без перезаписи существующего файла; добавлен тест реальной рабочей папки. Неявной миграции чужой БД нет.

## 2026-11-23 — Видео у сокомандника; терминальный Git пока недоступен

По прямому указанию пользователя запись/YouTube переданы сокоманднику. Повторные terminal Git-проверки обычной и расширенной среды дали DNS-ошибку github.com. Браузерное соединение восстановлено перезапуском сессии; исходники доставляются обычными коммитами авторизованного FloUrenzz. Force-push не используется, локальная и удалённая истории сохраняются отдельно до нормального fetch.
