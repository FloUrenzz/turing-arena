# Зафиксированные результаты аудита

`results.json` и `fault-results.json` — исходная независимая проверка до исправлений. `followup_results.json` — первый повтор; `followup_final_scope.json` — ограниченная проверка scope-фикса; `final-regression.json` — последний повтор того же набора после расширения разбора.

Отчёты относятся к разным SHA-256 модулей и не заменяют друг друга. Финальная регрессия: 20 содержательных зачётов из 25, 4 безопасных уточнения/отказа, один незачёт покрытия; неизвестные 10/10. E/A/S: 5/5,4/5,5/5. Это известный набор после исправлений, не новое независимое измерение и не оценка человечности.

Полные вопросы, ожидаемый смысл, ответы и состояния сохранены в JSON. Оценки содержания и ограничения описаны в `docs/pipeline/audit.md` и `audit-followup.md`. Для новой оценки используйте новый набор вопросов и отдельный выходной файл; не перезаписывайте эти исходные результаты.
