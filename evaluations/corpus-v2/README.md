# Проверка интеграции корпуса, 2026-11-23

- `integration-baseline.json`: первоначальная маршрутизация 150 известных примеров, до сохранения порядка значимых слов. Это не слепой тест, авторской оценки правильности ответов нет.
- `integration.json`: повтор той же известной регрессии после исправления; содержит SHA256 трёх модулей, БД, все ответы, фактические spawn и две выдачи с задержкой.106/150 выбираются из корпуса; это счётчик маршрутов, не 106 правильных ответов.
- `audit.json`: независимые новые контрпримеры, затем отдельно проверка прежнего исходника из локального 86c2488 и исправленного файла. Все восемь первоначальных ошибок сохранены. Исправленная версия отвергает эти конкретные переносы.
- Полный текст и границы проверки: `docs/pipeline/audit-corpus-v2.md`.

`python -X utf8 scripts/evaluate_corpus.py` воспроизводит интеграционную регрессию и перезаписывает integration.json; перед новым исследованием сохраните его под новой версией. Эта команда не воспроизводит независимую исходную оценку. `python -X utf8 scripts/benchmark.py --count 1000 --corpus data/dialogue.sqlite3` измеряет прямой движок без spawn/ожидания, с запретом сетевых вызовов. Физически отключённый финальный ноутбук и голосование зрителей не проверены.
